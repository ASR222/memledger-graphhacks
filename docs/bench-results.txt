== FINDING: queries.SEED is incompatible with FalkorDB 6.0.2 ==
SEED = "UNWIND $agents ... MERGE ... WITH count(*) AS _ UNWIND $sources AS s MERGE (y:Source ...)"
On 6.0.2 the second UNWIND+MERGE creates only the FIRST source ('alerts'); all 3 agents are created.
Minimal repro (redis-cli):
  GRAPH.QUERY t "UNWIND [1,2] AS a MERGE (x:A {id:a}) WITH count(*) AS _ UNWIND [1,2,3] AS s MERGE (y:S {id:s}) ON CREATE SET y.k = s"
  -> MATCH (y:S) returns only 1 (expected 1,2,3). Without the leading MERGE+WITH, all 3 are created.
Effect: every tenant created on 6.x has 1 of 5 sources, so log_episode raises UnknownReference for
'runbook', 'app-logs', 'webhook', 'fwd-logs'. Not fixed here (out of C6 scope): fix = run the
agents part and the sources part of SEED as two queries in schema.seed.
